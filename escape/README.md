# 大坂城脱出 ― 大坂の陣 五つの任務（試作 v0.4）

燃え落ちる大坂城から、仲間と力を合わせて大川の小舟まで逃げのびる、スマホ向けの協力脱出ゲームです。1〜4人で遊べます。

マップは「大阪城さんぽ」（32miya/32miya-osaka-castle）の豊臣期の大坂城・夏の陣「落城」の場面を、そのまま複製して使っています。大阪城さんぽ本体には手を加えていません。

## 遊び方

- **ひとりで遊ぶ**：すぐに始まります
- **部屋をつくる**：4桁の部屋番号が出るので、仲間に伝えます（「招待リンクを送る」も使えます）
- **部屋に入る**：仲間から聞いた4桁の番号を入れます
- 操作：左のパッドで移動、右側で見回し、**調べる**は長押し、**しゃがむ**で見つかりにくくなる
- PC：WASD で移動、E（またはスペース）で調べる、C でしゃがむ、Shift で走る

## 面（ステージ）　v0.5：五つの面

クリアすると次の面に進めます。クリアした面までは、部屋をつくるときや結果画面の「面をえらぶ」から好きな面を選んで始められます。任務には「手分けして同時に進められるもの」と「順番に進むもの」があり、いま進められる任務は画面左上にまとめて表示されます（☑＝済み、（手がかり）＝やらなくても進めるが答えのヒントになる）。

**其の一　城下の密書**（朝・上町の城下町と寺町）
町年寄の話を聞く → 【同時に】町娘・商人・女房に聞き込む（手がかり）／寺町の住職から合言葉の控えをもらう／密書を隠した店を突き止めて探す → 三の丸の門番に合言葉を答える → 門をくぐる

**其の二　真田丸の狼煙**（夕・惣構の南）
物見の話を聞く → 【同時に】陣の荷から火打ち石を探す／陣太鼓の撥を探す → 篝火を起こす → 狼煙台に正しい順で火を入れる → 陣太鼓を2人同時に打つ → 真田丸へ

**其の三　二の丸の導火線**（夜・二の丸）
番頭の話を聞く → 内通者の書付を探す → 【同時に】広間・書院・奥座敷の導火線を切る／井戸の水で火薬樽を湿らせる → 番頭に知らせて逃げた方角を聞く → 正しい口へ

**其の四　裸城の宝**（昼・本丸と二の丸）
目利きの話を聞く → 【同時に】石灯籠から長持の鍵を探す／本物の名物3つを長持へ運ぶ → 【同時に】荷車の轅を持ち上げる／半鐘を鳴らして番兵の気をそらす → 大手門から出る

**其の五　落城の夜**（夜・本丸から大川へ）
侍女の謎かけで抜け道の絵図を探す → 幟の家紋を集めて錠前を開ける → 閂を2人同時に押さえる → 茶室で替えの縄を探して井戸を直す → 極楽橋の火を消す → 大川の小舟へ

- 答え（店・場所・順番・家紋・方角など）は毎回変わります
- 聞いた話や見つけた手がかりは「手控え」ボタンにたまり、仲間どうしで共有されます
- ミニマップをタップすると全体マップ（仲間の位置と目的地🚩）が開きます。もう一度タップで戻ります（PCは M キー）
- 町の人には誰にでも話しかけられます（近づいて「話しかける」、またはタップ）
- 右上の「≡」からタイトルに戻れます（主が戻ると部屋は閉じます）
- オンラインで通信が切れても、自動で部屋に戻ります。ページを閉じてしまっても、20分以内ならタイトルの「前の部屋に戻る」で続きから参加できます
- 制限時間は其の一〜四が10分、其の五が15分。残り1分になると全員の画面に大きく告知が出ます

## しくみ（無料で動かすための構成）

- 公開：GitHub Pages（無料）
- 通信：PeerJS（WebRTC の P2P）。部屋を作った人の端末が「主」になり、進行・追手・当たり判定を計算して、毎秒10回みんなに送ります
- 接続のなかだち（シグナリング）は PeerJS の無料公開サーバー（0.peerjs.com）を使っています。サーバー代はかかりません
- 注意：モバイル回線どうしなど、回線の組み合わせによっては P2P がつながらないことがあります。その場合は Wi-Fi で試してください

## ファイル

- `index.html`：ゲーム本体（大阪城さんぽの単一HTMLに脱出ゲーム層を差し込んだもの）
- 画像：大阪城さんぽの `../assets/` を共有。仲間のしゃがみ姿は `crouch.webp`
- `src/escape.js`：脱出ゲーム層のソース
- `src/build.py`：大阪城さんぽの index.html（`src/base.html`）から、このゲームの index.html を作るスクリプト
  - 大阪城さんぽのマップを更新したら：新しい index.html を `src/base.html` に置いて リポジトリ直下の index.html を `escape/src/base.html` にコピーし、escape フォルダで `python3 src/build.py src/base.html index.html ../`
