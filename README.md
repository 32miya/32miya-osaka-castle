# 大阪城さんぽ

大阪城の本丸・二の丸と、太閤・豊臣秀吉の時代の大坂城をスマホで歩いて巡れる3D散策アプリの試作品。three.js製の単一HTMLです（「松本城さんぽ」と同じ仕組み）。

- 現代: 昭和の天守閣（内部1〜8階・展望台）、桜門と蛸石、極楽橋、大手門・千貫櫓、西の丸庭園、梅林、豊國神社 など
- 太閤の時代（1590年代ごろ）: 黒漆と金箔瓦の天守（穴蔵〜最上階・廻縁）、黄金の茶室、詰ノ丸、千畳敷の表御殿、山里丸、屋根付きの極楽橋、大名屋敷、城下町（上町）、大川の船 など
- 石垣: 反りのある「扇の勾配」、出隅の「算木積み」、大名の刻印、蛸石・肥後石の巨石、枡形（桜門・大手門・京橋口）、塀の狭間、櫓の石落とし
- 惣構（太閤の時代）: 北の大川・西の東横堀川・東の猫間川・南の空堀と土塁で城下町ごと囲み、通りごとの木戸、寺町、高麗橋、惣構の門を再現（距離は縮めています）
- 天守の各階は用途ごとに作り分け（現代: 博物館の展示、豊臣期: 武具・宝物・茶室・衣装・書院など想像）
- 太閤の時代の姿は屏風絵などをもとにした想像復元です。
- 名所の写真は Wikimedia Commons から検索して表示します（撮影者・ライセンスを併記）。
